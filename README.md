# Change Request Form

A client-facing change request form for software development projects. Clients can submit categorized change requests with descriptions and reference images, then save the completed form as a PDF.

## Features

- **Two request types**: Cosmetic UI changes (covered in revision rounds) vs. specification changes/new features (billed separately)
- **Multiple requests per submission**: Add as many change requests as needed in a single form
- **Photo uploads**: Attach reference images to each request
- **PDF export**: Save the completed form via the browser's print-to-PDF
- **Summary stats**: Auto-calculated totals for each request type with billing warnings

## Usage

Open `index.html` in a browser. No build step or dependencies required — it's a single self-contained HTML file.

## Customization

Update the header card, contract terms, and revision round options in the HTML to match your project's agreement.
